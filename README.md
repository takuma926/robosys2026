# robosys2026

このリポジトリは、千葉工業大学のロボットシステム学の授業で作成しているソフトウェアパッケージです。

## plus コマンド

標準入力から受け取った数値をすべて足し算して出力するコマンドです。

### 使い方

bash
$ seq 5 | ./plus
15

### ソフトウェア要件

- Python 3 (3.10以上)
- Bash
